# AZBA | عزبة — منصة الاستثمار وإدارة الثروة الحيوانية

منصة رقمية متكاملة للاستثمار المنظم في الثروة الحيوانية وإدارة المزارع والشؤون البيطرية والمالية، تبدأ من مصر وقابلة للتوسع عربيًا.

> **وضع تجريبي (Sandbox):** الدفع تجريبي ولا يتم تحصيل أموال حقيقية. لا يمكن تفعيل التحصيل الحقيقي إلا بعد استكمال المتطلبات القانونية والتراخيص.

---

## 1. المزايا

- **موقع عام** (Next.js): الرئيسية، فرص الاستثمار، تفاصيل المشروع، كيف نعمل، من نحن، الشفافية، المخاطر، الأسئلة الشائعة، الشروط والخصوصية.
- **لوحة المستثمر**: نظرة عامة، الاستثمار، المحفظة، مشاريعي، المحفظة المالية، الإشعارات.
- **سوق الاستثمار**: تصفح وفرز وبحث ومقارنة المشاريع، وحجز الأسهم وتأكيد الاستثمار بدفع تجريبي.
- **لوحة الإدارة**: مؤشرات المنصة، المستخدمون والأدوار، المشاريع، الاستثمارات، سجلات التدقيق.
- **إدارة المزارع**: المزارع، المباني، الحظائر، الحيوانات، الأوزان، التغذية، السجلات الصحية، اللقاحات.
- **البوابة البيطرية**: البحث عن الحيوان (QR)، السجل الصحي، التقارير البيطرية واعتمادها.
- **المالية والمحاسبة**: شجرة الحسابات، قيود اليومية (Double-Entry)، المصروفات، ميزان المراجعة، الأرباح والخسائر، التوزيعات.
- **الأمان**: JWT، تشفير كلمات المرور (bcrypt)، RBAC بالأدوار والصلاحيات، Rate Limiting، Helmet، CORS، سجلات تدقيق.
- **جاهز للجوّال (PWA)**: أيقونة وملف manifest وتخطيط متجاوب RTL.

## 5. التشغيل لأول مرة

### 5.1 قاعدة البيانات

```bash
# إنشاء قاعدة البيانات
psql -U postgres -c "CREATE DATABASE azba;"
```

### 5.2 إعداد البيئة

تم إنشاء ملفات `.env` في الجذر و`packages/database` و`apps/api` و`apps/web`. عدّل `DATABASE_URL` و`JWT_SECRET` حسب بيئتك.

### 5.3 التثبيت والهجرة والبيانات التجريبية

```bash
# تثبيت الاعتماديات لكل حزمة
cd packages/shared && npm install && npm run build
cd ../ui && npm install && npm run build
cd ../database && npm install
cd ../../apps/api && npm install
cd ../web && npm install

# توليد عميل Prisma وتطبيق الهجرات
cd packages/database
npx prisma generate
npx prisma migrate deploy      # أو: npm run db:migrate

# البيانات التجريبية (أدوار، صلاحيات، شجرة حسابات، مستخدمين، مزرعة، مشروع)
npm run db:seed
```

### 5.4 التشغيل

```bash
# API على المنفذ 4000
cd apps/api && npm run build && npm run start

# الموقع على المنفذ 3000
cd apps/web && npm run dev
```

- الموقع: <http://localhost:3000>
- API: <http://localhost:4000/api>
- توثيق API (Swagger): <http://localhost:4000/docs>

## 9. النشر (Deployment)

- بناء الواجهة: `cd apps/web && npm run build`
- تشغيل الواجهة: `npm run start` (يتطلب `NEXT_PUBLIC_API_URL`).
- بناء الخلفية: `cd apps/api && npm run build && npm run start:prod`
- متغيرات إنتاج إلزامية: `NODE_ENV=production`, `DATABASE_URL`, `JWT_SECRET`, `JWT_REFRESH_SECRET`, `CORS_ORIGINS`.
- يجب تكوين HTTPS وإدارة الأسرار والنسخ الاحتياطي التلقائي قبل استقبال مستخدمين حقيقيين.
